# Exceptions for ci/check_lockfile.sh.
#
# The check requires every yarn.lock entry to come from the npm registry and
# to have an integrity hash. List the entries that legitimately do not here,
# one per line, with the reason after "#":
#
#   package <name>@<version>   # reason
#
# <name>@<version> is the package name and the exact version from the entry's
# "version" line in yarn.lock. The exception skips both checks for exactly
# that version. A version bump needs a new line, on purpose: someone looks at
# it again. An exception without a reason fails the check.
#
# Example (not active): formik replaced by our own fork, fetched from git, so
# the entry has no registry URL and no hash:
#
#   package formik@2.4.9   # our fork with the fix for issue 1234, until upstream releases 2.4.10
#
# An exception that no longer matches an entry only prints a warning. Remove
# it when that shows up.
